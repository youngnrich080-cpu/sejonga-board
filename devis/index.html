Devis

디나이스(Denise)가 만든 PC용 쇼츠 편집 프로그램

Devis는 긴 영상이나 해외 쇼츠·릴스를 세로 쇼츠로 다시 편집하는 윈도우 PC 프로그램이에요. 자막, 나레이션(TTS), 좌우 반전, 원본 자막 가리기, 내보내기를 한 화면에서 해요.

디나이스 안에서 쓰는 내부용 프로그램이고, 판매하거나 누구나 내려받게 공개하지 않아요.

구글 드라이브 연결

Devis는 사용자가 원할 때만 구글 계정을 연결해, 내보낸 영상을 사용자가 고른 드라이브 폴더에 올려요. 올릴 폴더를 고를 수 있게 폴더 목록을 읽는 것 말고는 드라이브의 다른 파일을 읽거나 바꾸거나 지우지 않아요.
