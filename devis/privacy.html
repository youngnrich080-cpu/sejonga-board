시행일: 2026년 11월 2일 · 운영: 디나이스(Denise)

1. 어떤 정보를 쓰나요

  • 구글 계정 이메일 주소: 어떤 계정에 연결됐는지 프로그램 화면에 보여 주려고 읽어요.
  • 구글 드라이브 폴더 이름과 목록: 영상을 올릴 폴더를 고를 수 있게 보여 주려고 읽어요.
  • 사용자가 내보낸 영상 파일: 사용자가 올리기를 켜거나 [드라이브에 올리기]를 누를 때만, 사용자가 고른 폴더에 올려요.

드라이브의 다른 파일 내용은 읽지 않고, 바꾸거나 지우지 않아요.

2. 어디에 저장하나요

구글 연결 정보(로그인 토큰)와 이메일 주소는 그 사용자의 PC 안에만 저장돼요. 디나이스나 다른 서버로 보내지 않아요. Devis는 따로 서버를 두고 사용자 정보를 모으지 않아요.

3. 누구와 나누나요

구글에서 받은 정보는 누구에게도 팔거나 넘기지 않고, 광고에 쓰지 않아요. 영상 올리기 기능 말고 다른 목적으로 쓰지 않아요.

Devis's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

4. 연결을 끊고 지우려면

  • Devis 안에서 구글 연결을 끊으면 PC에 저장된 연결 정보가 지워져요.
  • 구글 계정 › 보안 › 서드 파티 앱 및 서비스에서 Devis 접근을 언제든 없앨 수 있어요.
